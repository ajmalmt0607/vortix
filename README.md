# VORTIX

**AI Restaurant Operating System** — connects restaurant operations (POS, inventory, procurement, finance, HR, CRM, marketing, and AI agents) into one intelligent platform.

## Frontend

The frontend lives in [`/frontend`](./frontend) — a React + TypeScript + Vite app styled with Tailwind CSS and animated with Framer Motion.

```bash
cd frontend
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`, `npm run preview`.
